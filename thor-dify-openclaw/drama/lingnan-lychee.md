# AI 短劇：《一騎紅塵》（嶺南荔枝 · 穿越現代）

技術骨架不變：語音 → 一小段 Dify → 飛鴿先看 → 驛馬夾送。  
只換**皮膚**：荔枝是要夾的物，貴妃是交給誰，長安是送到哪。

一句話：**飛鴿探枝，驛馬送荔，聖旨只有三欄。**

## 角色對位

| 劇中 | 現場誰演 | 只做什麼 | 不做什麼 |
|---|---|---|---|
| 飛鴿傳書 | Crazyflie | 低空看荔枝在哪，傳回「枝頭有果」 | 不叼荔枝、不空投 |
| 快馬加鞭的驛馬 | Dogzilla | 夾起荔枝盒，送到人面前 | 不飛、不宣旨 |
| 宮門掌事（現地） | Reachy | 聽聖旨、報「荔枝到了」 | 不夾、不跑腿 |
| 捧旨小黃門（隨身） | K10 | 螢幕出示聖旨，A 準奏／B 駁回 | 不當驛馬 |
| 驛丞／現代調度 | Thor + Nvidia | ASR、VLM 認荔枝、叫鴿子與馬 | 不另載一套模型 |
| 聖旨本身 | Dify 三節點 | 只寫：何物、何地、給誰 | 不演戲、不動身體 |
| 楊貴妃 | **AI 補的人**（夢境唐妝＋現代投影） | 開口要荔、荔到一笑 | 不走路、不夾、不按 A |

古時：飛鴿報「嶺南果熟」，驛馬日夜換騎，紅塵一騎，妃子笑。  
現在：鴿子變成奈米機，驛馬變成機器狗，驛站在 Thor 裡，聖旨縮成 JSON。

## 楊貴妃怎麼處理

她是**收件人**，不是身體。JSON 裡的 `recipient` 就是她。

真拍只收機器人與 Thor，**貴妃整段用 AI 補**，理由很實際：她只要兩拍（要荔、一笑），臉要一眼能認，又不必踩進 Dogzilla 的動線。

| 層 | 誰畫 | 出現在哪 | 提示 |
|---|---|---|---|
| 夢裡的楊貴妃 | Thor ComfyUI／人像模型 | 鏡 1–2 華清宮、吃荔、紅塵對切 | 唐妝、花鈿、荔枝在手，不要現代鏡頭 |
| 穿越後的貴妃 | 同一張臉的現代變體 | 鏡 3 開口、鏡 8 接荔微笑 | 便服或淡唐元素，坐沙發，對準 Reachy 說話 |
| 聲音 | Thor TTS（或後製） | 鏡 3「把那盒嶺南荔枝送到沙發給我。」 | 不要讓 Reachy 扮貴妃；Reachy 只報「荔枝到了。」 |

剪的時候：AI 貴妃看向畫面外＝看向真拍的 Reachy；手伸向畫面外＝接真拍 Dogzilla 放下的荔枝盒。中間用紅絹／閃白接，不必真的同框。

不要把貴妃疊到 K10 或 Reachy 臉上——一個是捧旨，一個是掌事，妃子笑才是全片句點。

## 三分鐘分鏡

片長建議 **90–150 秒**。A  lev 全是真機器人；B  lev 才用 Thor ComfyUI／影像模型做「唐朝夢」。

| 鏡號 | 畫面 | 現場怎麼拍 | 旁白／台詞 |
|---|---|---|---|
| 1 冷開 | 螺旋槳吹起紅絹或紙屑，疊半透明長安城 | Crazyflie 室內 50cm 起飛 | 「一騎紅塵妃子笑」 |
| 2 穿越 | 紅絹落下，露出現代茶几上一盒荔枝 | 靜鏡 | 「無人知是荔枝來——直到今天。」 |
| 3 開口 | 貴妃對準 Reachy 或手持 K10 | 語音進 Thor | 「把那盒嶺南荔枝送到沙發給我。」 |
| 4 聖旨 | K10 出三行：拿／到／給 | Dify 回 JSON | 螢幕即聖旨，不必念公文 |
| 5 準奏 | 手指按 K10 的 A | 確認閘 | 一聲「準。」 |
| 6 飛鴿 | Crazyflie 掠過荔枝盒，鏡頭給 VLM | `crazyflie_look` | 「枝頭有果。」 |
| 7 驛馬 | Dogzilla 夾盒、穿過房間、放到貴妃手邊 | `grasp` → `goto` → `release` | 蹄聲用狗步點配樂 |
| 8 妃子笑 | Reachy 轉頭，人接過荔枝笑一下 | `reachy_speak` | 「荔枝到了。」黑場 |

Dify 仍然只出這一包（聖旨）：

```json
{
  "intent": "fetch",
  "item": "嶺南荔枝",
  "dest": "沙發",
  "recipient": "貴妃",
  "scout": "crazyflie",
  "confirm": true,
  "say": "飛鴿先探枝頭，驛馬隨後將荔枝送至貴妃案前"
}
```

室內不飛就 `"scout": "none"`，第 1、6 鏡改成 Reachy 看一眼茶几。

## 怎麼拍成「AI 短劇」而不另起一攤

1. **A  lev（真）**：四機位或手機跟：K10 螢幕、Crazyflie、Dogzilla、貴妃臉。這是「現代」。
2. **B  lev（夢）**：Thor 既有 ComfyUI 出三張——嶺南枝頭、驛道紅塵、唐宮夜宴——只在鏡 1、2 各切 1–2 秒。
3. **聲**：Reachy 念第 8 鏡；開場詩可用 Thor TTS，不要讓 Dify 寫劇本。
4. **剪**：現代畫面偏冷、夢境偏暖，中間用紅絹當轉場，對上「紅塵」。

作業／Demo 對長官就講這三句：

- 飛鴿傳的是**情報**，不是荔枝。
- 驛馬傳的是**果子**，換騎換成 MCP。
- 聖旨短，是因為課程要沾 Dify，不是因為唐朝公文變少。

試拍口令（Reachy 或 K10）：

```text
把那盒嶺南荔枝送到沙發給貴妃
```
